# Aethelgard World Bible

A structured reference for Aethelgard: Earth in 2147, a neo-Victorian high-tech society reshaped by the Great Network Collapse.

## How to Use This Repository
1. Read [CANON_STATUS.md](CANON_STATUS.md) before adding major setting details.
2. Treat "Agreed Core Canon" as established. Items under "Working Details" are proposals, not immutable facts.
3. Store one subject per file. Update the relevant source file when canon changes.
4. Keep the lore causally consistent; record unresolved questions rather than silently inventing answers.
5. The compact [World Core](lorebook-export/world-core.md) is intended for a permanently active Lorebook entry. Longer articles should be imported as keyword-triggered entries.
6. For continuity between chats, start with [Conversation Transfer Notes](canon/conversation-transfer-notes.md) and then read the relevant source files.
