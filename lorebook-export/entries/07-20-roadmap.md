## Recommended Lorebook structure

- **00 — WORLD CORE:** Always active; short and dense. It should contain only the setting's essentials and consistency rules.
- **01–20 — WORLD LORE:** Activate by keywords, not all at once. Use concise, distinctive trigger terms for each topic.
- Keep each detailed entry focused on one question. For example, the Collapse, the New Internet, and the rise of corporate dynasties should be separate entries.
- If the Lorebook system offers a constant/always-active mode, use it only for WORLD CORE. Avoid making every entry permanent, because this wastes context.
- English titles and content are preferred for use in an English-language roleplay setup. The creator can keep planning notes in Russian.
