01 / Navigate

Начинаем с одного важного региона. Масштаб плавный: географические объекты постепенно раскрываются при приближении — от Альп до улиц и контуров зданий там, где они есть в источнике данных.

02 / Search place

Поиск по открытым географическим данным.

03 / Relief model

Викторианский режим перекрашивает доступные векторные слои в бумажно-сепийную палитру и добавляет лёгкую печатную фактуру. Это стиль отображения, а не копия исторической карты.

Рельеф берётся из открытой модели высот. Собственные GeoJSON-слои можно накладывать отдельно и выключать независимо от подложки.

04 / Слои базовой карты

Отключай ненужные детали исходной географии по группам. Рельеф, гидрография, растительность, транспорт и подписи управляются раздельно.

05 / Авторские слои

Накладывай собственные GeoJSON-файлы поверх базовой карты: будущие города, новые дороги, кварталы, зоны и другие придуманные объекты. Каждый файл станет отдельным слоем.

Пока нет авторских слоёв. Импортируй файл .geojson, чтобы добавить собственные объекты.
Свои слои появятся здесь.

07 / Data provenance

Карта и дорожные/городские объекты: OpenStreetMap contributors, через открытые векторные тайлы OpenFreeMap / OpenMapTiles. Модель высот: AWS Open Data · Terrarium elevation tiles. Поиск мест: Photon by Komoot. Рендеринг: MapLibre GL JS.

Покрытие зависит от конкретного места. На высоком масштабе могут быть видны здания, переулки, пути и остановки, если они размечены в открытых данных. Это не автоматически созданный план каждого здания и не точная карта 2147 года.
